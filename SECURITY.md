# Security policy

## Reporting a vulnerability

Open a private security advisory on GitHub:
<https://github.com/mrpkk/agent-trust-scan/security/advisories/new>

Do not open a public issue for a vulnerability in a live agent or a leaked key.

## Scope

This repository is a static scanner. It does not hold funds, keys, or customer data. The paid review is scoped per engagement; the client keeps custody of keys and funds.

## What we will not do

- custody client funds;
- process payments for third parties;
- promise that an audit makes an agent "100% safe";
- test against a live system without written permission and a scoped environment.
